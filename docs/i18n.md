# i18n — French & Arabic RTL

**Branch:** `056-i18n`
**Stack:** `i18next` 25 + `react-i18next` 15 + `i18next-browser-languagedetector` 8, `date-fns` / `Intl`, Tailwind `rtl:` variant, Noto Sans Arabic

## Languages
- `en` (default, fallback), `fr`, `ar` (RTL)
- `supportedLngs = ["en","fr","ar"]` in `src/i18n/config.ts:23`
- Detection order: `localStorage` → `cookie` → `navigator`, caches `localStorage` + `cookie` (`i18nextLng`)

## Files
```
public/locales/{en,fr,ar}/{common,auth,events,forum,profile,admin,errors}.json
src/i18n/config.ts — init, resources via static import, dir sync to <html>
src/i18n/locales/{en,fr,ar}/*.json — source of truth (copied to public for http fallback)
src/components/shared/LanguageSwitcher.tsx — Select with Globe, aria-label, persists
src/lib/format.ts — formatDate/formatNumber via Intl
```

## Usage
```tsx
import { useTranslation } from "react-i18next";
const { t, i18n } = useTranslation("common");
t("nav.home") // Home / Accueil / الرئيسية
t("hero.title") // with \n via whitespace-pre-line
i18n.changeLanguage("ar") // sets localStorage, cookie, <html lang dir>
```

## RTL
- `src/i18n/config.ts:38` `i18n.on("languageChanged", lng => document.documentElement.dir = i18n.dir(lng))` + `lang`
- `src/index.css:8` `@custom-variant rtl` + `@import "@fontsource-variable/noto-sans-arabic"` + `html[dir="rtl"]` font
- `Shell` skip link uses `start/end` logical, `Header`/`AdminTable` use `rtl:` where needed; Tailwind `rtl:` enabled
- Test: `LanguageSwitcher.test.tsx` verifies `dir="rtl"` for `ar`

## SEO
- `SEO.tsx:10` adds `hreflang` `en/fr/ar/x-default` via `getCanonicalUrl()` base (same URL, SPA agnostic; prefix `/fr` deferred per plan)
- `html lang` sync ensures axe `html-has-lang` passes for all locales

## Dates
- `src/lib/format.ts` `formatDate(date, locale)` via `Intl.DateTimeFormat`; used in `NewsDetail`, `MemberDetail`, `EventDetail` (replace `toLocaleDateString`)

## Adding a language
1. Add to `supportedLngs` in `config.ts`
2. Create `src/i18n/locales/<lng>/*.json` + `public/locales/<lng>/*.json` (copy `en` then translate)
3. Add option to `LanguageSwitcher.tsx`
4. Run `npm run test:run` + `scripts/check-i18n-keys.js`
